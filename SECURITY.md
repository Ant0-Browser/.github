# Security policy

Please report security problems privately. Don't open a public issue.

## How to report

- **On GitHub:** open the repository's **Security** tab and choose **Report a vulnerability**. Only
  the maintainers can see the report.
- **By email:** security@ant0.link

Please include:
- what you found and where (repository, version or commit);
- steps to reproduce it;
- what an attacker could do with it.

## What happens next

We confirm that we received your report and keep you updated while we work on it. We'll tell you when
a fix is released, and credit you in the advisory if you'd like.

## Scope

This policy covers the code in this organization's public repositories. For the Ant0 app, the Ant0
Browser engine, the cloud service and ant0.link, use the same channels. Everything is listed at
https://ant0.link/.well-known/security.txt

Please don't access other people's data, disrupt the service or run automated scans against
ant0.link while testing.
