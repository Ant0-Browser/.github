# Contributing

Thanks for helping with Ant0. This guide applies to every public repository in the Ant0-Browser
organization, unless a repository has its own.

## Before you start

- For a bug, open an issue with the bug form first. Include your Ant0 version and your system.
- For a feature or a larger change, open an issue first so we can agree on the approach before you
  write the code.
- Security problems go through [SECURITY.md](SECURITY.md), never a public issue.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep each pull request to one change. Small ones are reviewed faster.
3. Add or update tests for what you changed, and run the repository's checks locally.
4. Update the docs or README if the behaviour changes.
5. Open the pull request and fill in the template.

Maintainers review every pull request. We may ask for changes, and we may decline a change that
doesn't fit the project. We'll say why.

## Licence and CLA

Contributions are licensed under the repository's licence (see its `LICENSE` file). Before we can
merge your first pull request, you'll be asked to sign our Contributor License Agreement (CLA). A bot
will guide you through it on the pull request. Until the CLA bot is live, please open an issue first
and we'll follow up.

## Conduct

Be respectful and assume good intent. Keep discussions about the code. Maintainers may remove
comments or block accounts that are abusive or off topic. Use of Ant0 itself is governed by the
[acceptable use policy](https://ant0.link/legal/acceptable-use).
